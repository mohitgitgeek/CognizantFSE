# Upskilling Solutions

Complete runnable solutions for the Upskilling exercise PDFs.

## Contents

- `web-portal/` — one Local Community Event Portal which demonstrates every HTML5, CSS3, JavaScript, and Bootstrap 5 exercise. Open `index.html` in a browser. The optional mock fetch uses JSONPlaceholder, so it needs internet access.
- `sql/event_portal_solutions.sql` — MySQL schema, the supplied data, and answers to all 25 ANSI SQL exercises. Run it in MySQL 8.0+.
- `core-java/` — answers to all 41 Java exercises. Compile and run an individual class; `JDBCExamples` needs a MySQL JDBC driver plus valid connection settings, and the client/server samples run in separate terminals.

Java 21 is required for exercises 29, 30, and 40. The other examples work with earlier Java versions unless noted in their source comments.
