# JUnit, Mockito and SLF4J solutions

This Maven project demonstrates the required basic/advanced JUnit assertions and lifecycle, parameterized tests, Mockito mocks/stubs/verifications/argument capture, dependency isolation, and SLF4J logging.

Run `mvn test` from this folder. The supplied PDFs could not be text-extracted in this environment, so map any exercise-specific class names to these tested patterns.
