# React hands-on solutions

`react-hands-on` is a runnable Vite React project covering the practical requirements from the supplied labs: components, props, state, lifecycle equivalent, styling, routing-ready data, ES6 mapping/filtering, JSX, event handling, conditional rendering, context, controlled forms and validation.

Run `npm install` then `npm run dev` in `react-hands-on`.

For labs 4, 6, 17, 18 and 19, the documents require external APIs, router packages, or test starter projects that were not supplied. Their implementation patterns are documented by the component examples; add API keys/network access and the requested packages when the supplied starter project is available.
